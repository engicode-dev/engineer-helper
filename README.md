# 🛠 Инженерный Помощник

Десктопное приложение на Python для инженеров-конструкторов и технологов. 
Объединяет в себе набор полезных калькуляторов в едином интерфейсе.

## ✨ Функционал

Приложение включает в себя следующие модули:

*   **🧮 Инженерный калькулятор**: тригонометрия, корни, возведение в степень, «умное» закрытие скобок.
*   **📐 Геометрия**: расчет объема и площади поверхности для цилиндра, параллелепипеда и трубы. Возможность передачи объема в калькулятор веса.
*   **⚖️ Вес металла и материалов**: расчет массы детали по объему и плотности. База данных материалов (стали, цветные металлы, пластики, резина) с возможностью легкого расширения.
*   **📏 Допуски и посадки**: расчет предельных отклонений, зазоров и натягов для популярных посадок (H7/h6, H7/k6 и др.).
*   **🔩 Резьбы**: справочник метрических резьб (от M2 до M20) с расчетом среднего и внутреннего диаметров.
*   **🔥 Сварные швы**: расчет площади сечения, массы наплавленного металла и расхода электродов для углового шва.

## 🚀 Как запустить

1.  Убедитесь, что у вас установлен **Python 3.10+**.
2.  Клонируйте репозиторий (обратите внимание на имя папки):
    ```bash
    git clone https://github.com/engicode-dev/engjineer-helper.git
    cd dev-engineering/engineer_helper
    ```
3. Создайте и активируйте виртуальное окружение (рекомендуется):
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Для Linux/macOS
    # .venv\Scripts\activate   # Для Windows
    ```
4. Установите зависимости (если они есть):
    ```bash
    pip install -r requirements.txt```
    ```
5. Запустите приложение:
    ```bash
    python main.py
    ```
   
## 📂 Структура проекта

```
EngineerCalc/
├── main.py              # Точка входа, главное меню
├── core/                # Ядро (стили, общие данные)
├── calculators/         # Модули калькуляторов
├── data/                # JSON-файлы с данными (материалы, допуски)
├── fonts/               # Шрифты (ГОСТ)
└── utils/               # Вспомогательные функции (загрузка данных, шрифтов)
```

## 🛠 Технологии

* Python 3
* Tkinter (GUI)
* JSON (хранение данных)
* Шрифт GOST Type A (для аутентичного инженерного вида)
